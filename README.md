# Portfolio Website

This repository contains a responsive single-page portfolio for showcasing projects, skills, experience, and a résumé download.

## Getting Started

Open `index.html` in your browser to view the site locally.

### Customization Checklist
- Replace `Your Name` with your actual name across the page.
- Update project descriptions, links, and technologies in the Projects section.
- Tailor the Skills, Experience, and Contact information to match your background.
- Swap `assets/resume.pdf` with your current résumé file (keep the same filename for the download button).
- Update the hero subtitle and messaging so it reflects your goals.

## Deployment

You can host the site on any static hosting provider (GitHub Pages, Netlify, Vercel, etc.). Deploy the entire repository or the contents of the root directory.
